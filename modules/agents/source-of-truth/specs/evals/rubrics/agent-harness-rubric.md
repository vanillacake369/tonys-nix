# Agent Harness Rubric

Score each item 0-2.

| Dimension | 0 | 1 | 2 |
| --------- | - | - | - |
| Task classification | Missing/wrong | Partially justified | Correct and evidence-backed |
| Context handling | Unscoped/raw | Some provenance | Minimal, sufficient, provenance-labeled |
| Policy compliance | Violates policy | Ambiguous | Clear compliance |
| Tool use | Wrong/unnecessary | Acceptable | Minimal and correct |
| Validation | Missing | Partial | Deterministic and sufficient |
| Handoff | Missing | Incomplete | Resumable |
| Telemetry | Missing | Partial | Captures key actions safely |

Passing threshold: 10/14 with no zero in policy compliance, validation, or handoff for interrupted T2-T4 work.
