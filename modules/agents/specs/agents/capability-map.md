# Capability Map

| Capability | Initial mechanism | Rationale |
| ---------- | ----------------- | --------- |
| Router | Deterministic task classification | No agent needed yet. |
| Planner | Workflow or existing architect role | Use for T2-T4 only. |
| Researcher | Existing researcher role/subagent | Use for broad independent research. |
| Implementer | Existing implementer/direct execution | Existing tools are sufficient. |
| Reviewer | Existing reviewer or fresh-context workflow | Use for high-impact changes. |
| Security reviewer | Workflow first | Promote to agent only after repeated security-review workload. |
| Telemetry analyst | Deferred | Requires trace corpus first. |
| Postmortem curator | Template/workflow | Agent not justified yet. |
