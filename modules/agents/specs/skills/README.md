# Skills

No new canonical skills are defined in this phase.

Create a skill only after:

1. repeated failure or repeated context need is observed;
2. representative tasks are collected;
3. trigger precision and success criteria are defined;
4. a minimal skill is created;
5. evaluation shows improvement.

Candidate domains such as research synthesis, Spring backend, Rust storage, Kubernetes infrastructure, agent telemetry, and security review remain candidates only.
